# 遷城射程預覽

標出想打的座標，找出一次能罩住最多目標的遷城點，並即時預覽遷城後 60 格的攻擊範圍。

整個工具就是一個 `index.html`：計算都在瀏覽器裡跑，不連線、不操作遊戲，你標的座標只存在自己的瀏覽器。

## 怎麼用

1. **標目標**：點地圖，或在輸入框打 `x,y`（可一次貼上多個）。點已經標過的目標會移除它。
2. 右側「建議遷城點」會列出罩住最多目標的位置，以及打得一樣多的備選。目標太分散時會排出第 2、第 3 次遷城。
3. **試落點**：滑鼠移到地圖上會即時畫出「遷到這裡」的射程圈。
4. 選填「主城目前位置」，已經打得到的目標就不會再為它遷城。

語言會依瀏覽器設定自動選擇，也可以在右上角切換，或在網址後面加 `?lang=zh-Hant`、`?lang=zh-Hans`、`?lang=en`、`?lang=vi`。

## 限制

- 山賊營寨、別人的主城、各塊地屬於哪國，都是伺服器即時狀態，這頁看不到。首選站不下時改用備選。
- 主城實際落在大格裡哪一格要進遷城模式才知道，建議點會先扣 3 格誤差。

玩家自製的非官方工具，與遊戲公司無關。
