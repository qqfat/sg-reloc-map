# 迁城射程预览

标出想打的坐标，找出一次能覆盖最多目标的迁城点，并实时预览迁城后 60 格的攻击范围。

整个工具就是一个 `index.html`：计算都在浏览器里跑，不联网、不操作游戏，你标的坐标只存在自己的浏览器。

## 怎么用

1. **标目标**：点地图，或在输入框输入 `x,y`（可一次粘贴多个）。点已经标过的目标会移除它。
2. 右侧「建议迁城点」会列出覆盖最多目标的位置，以及覆盖一样多的备选。目标太分散时会排出第 2、第 3 次迁城。
3. **试落点**：鼠标移到地图上会实时画出「迁到这里」的射程圈。
4. 选填「主城当前位置」，已经打得到的目标就不会再为它迁城。

语言会根据浏览器设置自动选择，也可以在右上角切换，或在网址后面加 `?lang=zh-Hant`、`?lang=zh-Hans`、`?lang=en`、`?lang=vi`。

## 限制

- 山贼营寨、别人的主城、各块地属于哪国，都是服务器实时状态，这页看不到。首选站不下时改用备选。
- 主城实际落在大格里哪一格要进迁城模式才知道，建议点会先扣 3 格误差。

玩家自制的非官方工具，与游戏公司无关。
